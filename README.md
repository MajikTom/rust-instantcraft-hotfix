# Instant Craft — unofficial Carbon hotfix

This repository tracks MajikTom's compatibility patch for the Rust server plugin [Instant Craft](https://umod.org/plugins/instant-craft). The original plugin authors are Vlad-0003, Orange, and rostov114.

The initial commit contains upstream version 3.0.0. The patch branch is fix/carbon-crafting-queue. See LICENSE for the upstream MIT terms.
